02. Projetos Pessoais & Acadêmicos

API Ecommerce ↗

Uma API RESTful robusta construída para gerenciar o Back-end de uma loja virtual. O sistema possui autenticação de usuários, operações completas de banco de dados (CRUD) para produtos e toda a lógica de negócio de um carrinho de compras, desde a adição de itens até o checkout seguro.

  • Python
  • Flask
  • SQLite
  • ORM

Tela de Login ↗

Interface de autenticação moderna e totalmente responsiva, construída com foco em UI/UX Design. O projeto explora o conceito visual de Glassmorphism (efeito de vidro translúcido) e utiliza Flexbox para um alinhamento perfeito em qualquer dispositivo, criando uma porta de entrada elegante para sistemas web. Tecnologias: HTML5, CSS3.

  • HTML5
  • CSS3

Agregador de links Dinâmico ↗

Uma página responsiva desenvolvida para centralizar links profissionais e redes sociais. O grande diferencial é a implementação nativa de alternância de temas (Dark e Light Mode) utilizando manipulação de DOM e variáveis CSS, garantindo uma interface fluida e moderna.

  • HTML5
  • CSS3
  • JavaScript
